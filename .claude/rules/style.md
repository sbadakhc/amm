# Prose Style

## No em dashes

Never use the em dash character (`—`) anywhere in this project -- prose docs
(README.md, SPEC.md, AGENTS.md, docs/decisions/*.md), skill/rule/command files under
`.claude/`, code comments, docstrings, commit messages, or PR bodies. Use `--`
(double hyphen) for a parenthetical break instead, matching the convention already
used throughout AGENTS.md/CLAUDE.md and this file. Don't use a single hyphen `-` as a
substitute -- it reads as a hyphenated word, not a break.
